# ISYouth Worship

Aplicație PWA dedicată trupei de lăudători a tineretului bisericii „Isus Salvatorul Chișinău”.

## Funcționalități
- **Repertoriu**: gestionează cântările cu acorduri în paranteze pătrate.
- **Planificare**: creează setlist-uri cu transpunere automată cromatică.
- **Pe Scenă**: mod Live fullscreen, font mare, acorduri galbene, fundal negru.

## Tehnologii
React + Vite + Tailwind CSS + LocalStorage + vite-plugin-pwa

## Instalare & Dezvoltare
```bash
npm install
npm run dev
```

## Build pentru producție
```bash
npm run build
```

## Deploy
Poate fi deploy-at pe Vercel, Netlify, GitHub Pages, Render etc.
